# Code of conduct

Be respectful, technical and constructive.

This project deals with an unsupported compatibility setup, so different
machines can legitimately behave differently. Treat working reports and failure
reports as useful data rather than as proof that another user's configuration
is wrong.

When participating:

- focus criticism on code, behavior and reproducible evidence;
- avoid insults, harassment and personal attacks;
- do not pressure users to publish private logs or account information;
- never repost credentials, callback codes, tokens or private project data;
- keep discussions relevant to the repository.

Maintainers may edit or remove content that exposes secrets or violates these
guidelines, and may limit participation when necessary to keep the project safe
and useful.
